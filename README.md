Welcome to my repository for **Soft Computing**, implemented in **Python**. It contains assignments exploring fuzzy logic, neural networks, evolutionary optimization, and neuro-fuzzy systems from my 7th Semester Engineering curriculum.

## 🎯 Objective
The primary goal of this repository is to understand and implement core soft computing techniques, including fuzzy-set operations, fuzzy inference, perceptrons, feed-forward neural networks, genetic algorithms, and ANFIS.

## 📂 Repository Contents

The table below accurately reflects the implementations present in the source files:

| File | Topic / Assignment Description | Core Concepts Covered |
| :--- | :--- | :--- |
| `fuzzy_set.py` | **Fuzzy Set Operations** | Universe of discourse, union, intersection, complement, and difference using membership functions. |
| `fuzzy_controller.py` | **Washing Machine Fuzzy Controller** | Triangular membership functions, Mamdani min-max inference, rule evaluation, centroid defuzzification. |
| `perceptron.py` | **Logic Gates with Perceptrons** | Perceptron learning rule, linear separability, AND/OR/NAND gates, multi-perceptron XOR. |
| `slff.py` | **Single-Layer Feed-Forward Network** | Sigmoid activation, delta rule/gradient descent, mean squared error, OR-gate classification. |
| `mlff.py` | **Multi-Layer Feed-Forward Network** | Hidden layers, sigmoid activation, backpropagation, XOR classification. |
| `genetic_algorithm.py` | **Genetic Algorithm Optimization** | Selection, elitism, crossover, mutation, and comparison with hill climbing and random search. |
| `anfis.py` | **Adaptive Neuro-Fuzzy Inference System (ANFIS)** | First-order Sugeno inference, Gaussian membership functions, premise and consequent learning, nonlinear prediction. |

## 🚀 Getting Started

To run these programs locally on your machine, follow the instructions below.

### Prerequisites
You will need Python 3 installed on your system. The assignments use only Python's standard library, so no additional packages are required.

### Execution
1. **Clone the repository:**
     ```bash
     git clone https://github.com/Aradhya-Bhagwat/Soft-Computing.git
     cd Soft-Computing
     ```
2. **Run an assignment** (using `fuzzy_set.py` as an example):
     ```bash
     python fuzzy_set.py
     ```
     On systems where Python 3 is invoked as `python3`, use `python3 fuzzy_set.py` instead.
